# Проверки выпуска от 14.11.2026

Локально пройдены13 тестов Node.js: арифметика трёх форм, связь прибыли с изменением капитала, переходящие остатки, отказ при расхождении, неизвестном источнике и дубле, отрицательный прогноз, нулевая выручка, просрочка без даты, неверная дата и сумма, защита API, автоматическое принятие и отклонение снимка с сохранением предыдущего.

Браузер Chromium: ширины1440/768/390/320px. Проверены отсутствие горизонтального переполнения страницы, открытие и закрытие подробностей Escape, строки отчёта, смена месяца, увеличение текста, источники. Ошибок JavaScript не обнаружено. Проверены рабочий пустой режим и локальный импорт с сохранением признака демонстрации.

Опубликованный адрес проверен тем же браузерным сценарием. Файлы index.html, app.mjs, model.mjs, demo.json, styles.css сверены с локальной версией. GitHub Actions успешно выполняет финансовые тесты и сборку Pages. Это проверка выпуска, не сертификат доступности и не подтверждение фактической бухгалтерской отчётности.

Контрольные изображения: [компьютер](screenshots/desktop.png), [телефон](screenshots/mobile.png), [каталог компонентов](screenshots/style-guide.png). Снимки выполнены с DPR1 и синтетическими данными. Детальные результаты браузера находятся в `docs/browser-results.json`.

Известные границы: нет реальных адаптеров1С/банков/CRM; импорт только нормализованного JSON; таблицы раскрывают агрегированные строки, а не настоящую первичку; API требует защищённого размещения и корпоративной авторизации для промышленной эксплуатации.
